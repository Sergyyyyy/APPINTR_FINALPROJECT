# iPark - Parking Management System

This is a fullstack web app based in Django for the backend & HTML, CSS, JavaScript for the frontend.

## Features of the system include
1. CRUD Parking Spots
  - ADD, EDIT, DELETE, VIEW capabilities for the Parking spots in table form.
2. Transaction History
  - View of a transaction history (auditing log)
3. Rates/Hourly rate implementation
  - Able to implement and display business logic in the form of hourly rates.

This project is for the subject of INTERMEDIATE APPLICATION DEVELOPMENT (APPINTR).
